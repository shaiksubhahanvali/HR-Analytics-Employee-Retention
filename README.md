# HR Analytics – Employee Retention & Attrition Analysis

## Project Overview
This project analyzes employee attrition and retention trends to identify factors that influence employee turnover and support data-driven HR decisions.

## Objectives
- Analyze employee attrition across departments and job roles.
- Examine the relationship between attrition and monthly income.
- Study overtime, job satisfaction, and work-life balance.
- Identify employee retention improvement opportunities.

## Tools & Technologies
- Microsoft Excel
- SQL
- Tableau
- Power BI
- Power Query and DAX

## Key Analysis Areas
- Employee count and attrition rate
- Department-wise and job role-wise attrition
- Employee demographics and salary analysis
- Overtime and work-life balance
- Job satisfaction and promotion gaps

## Project Files
- Excel: Data analysis and dashboard
- SQL: Queries used for analysis
- Tableau: Interactive visualizations
- Power BI: Interactive dashboard
- Dashboard Screenshots: Visual project previews

## Key Learnings
Developed practical skills in data cleaning, data analysis, KPI development, dashboard creation, and communicating business insights.
